# SRBHelix — Official Releases

SRBHelix is a biomedical research platform for biological data analysis and discovery workflows.

## Downloads

Official application installers and release notes will be published on the
[GitHub Releases page](https://github.com/solankimedchem/SRBHelix-Releases/releases).

**Platform:** Windows x64

## Installation

Download the installer attached to the relevant release and follow the
installation instructions provided with that release.

## Release verification

SHA-256 checksums will be provided with releases where applicable to help
verify the integrity of downloaded files.

## Source code and privacy

The main SRBHelix application source code is maintained separately in a
private repository. Application source code is not distributed through
this public releases repository.

## Licensing

Applicable software licensing and third-party notices will be provided
with the public release.
